# صفحة هابي لايف للشقق المفروشة
نموذج أولي عربي RTL ومتجاوب مع الهاتف والكمبيوتر.

## التشغيل
1. فك ضغط الملف.
2. افتح index.html في متصفح Chrome أو Firefox.
3. للتعديل افتح index.html في Visual Studio Code.

## قبل النشر
- استبدل مربعات الصور بصور حقيقية للشقق.
- استبدل الرمز H بالشعار الرسمي.
- عدّل الألوان من بداية CSS داخل index.html.
- ابحث عن WHATSAPP_NUMBER واستبدل X برقم واتساب الإدارة بصيغة دولية، أرقام فقط.
- أضف رابط خرائط Google الدقيق.
- راجع المميزات وتأكد من توفرها فعلياً.

## ملاحظة
هذا نموذج تعريفي وليس نظام حجز أو دفع إلكتروني. يحتاج إلى استضافة ونطاق لنشره بعنوان خاص.
